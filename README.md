#  Dessert Recipe Website
##  Live Deployments & Documentation


- **Web Application**: [https://recipe-rzg5.vercel.app/](https://recipe-rzg5.vercel.app/)








##  About the Project
The Dessert Recipe Website helps users discover delicious desserts and learn how to prepare them. Users can search for recipes, view ingredients, and follow step-by-step instructions.

##  Features
- Search dessert recipes
- Display recipe ingredients
- Show cooking instructions
- User-friendly interface
- Fetch recipe data using an API

##  Technologies Used
- HTML
- CSS
- JavaScript
- API

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
